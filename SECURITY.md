# 🔒 Security Policy

## 🛡️ Supported Versions

We release patches and security fixes for the active major version:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or token privacy concern within **Antigravity Private Cockpit**:

1. **Do NOT open a public GitHub issue**.
2. Please report the issue privately by emailing the maintainer or opening a **Private Security Advisory** on GitHub.
3. We take all privacy and security concerns with the utmost urgency and will respond within 24 hours.
